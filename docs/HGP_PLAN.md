# HGP (História e Geografia de Portugal) — plano curto
Edifício existente: `historia` (Museu das Descobertas) → ativo; nome da disciplina «História e Geografia de Portugal».
Temas (competência = id do tema): XVIII, Liberalismo, XIX 2.ª metade, República, Ditadura, 25 de Abril, População, Lugares, Atividades, Lazer, Mundo. Campo `level` ('recuperacao5' | '6') por tema, trivial de alterar.
Motor: um template por item do banco (`content/historia/bank-*.ts`), sem parametrização de factos; embaralhar só a ordem de opções por `seed`. Formatos: mcq, order, numeric (anos), cloze; V/F = mcq com justificação; mapas = figura SVG (`figure`) + mcq. Pistas, explicação e feedback por opção errada em cada item. Tutor Tomé (tartaruga) com 11 lições. Conquistas HGP: 3.
Fontes: ver `HgpSource` por item. Revisão: Claude + Codex (factos); sem revisão docente.
