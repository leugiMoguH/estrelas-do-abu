## Pontos que merecem atenção especial
- Lei de 16-1-1773 («ventre livre» no Reino; quarta geração) e alvará de 19-9-1761 (itens 40, 54, 55): alcance exato.
- Itens 47–49 (milho/batata): batata «sobretudo a partir de meados do séc. XVIII» (difusão lenta; fonte: estudos de Coimbra); a ligação a aumento populacional vem das Aprendizagens Essenciais, sem fonte demográfica própria.

- Datas de Mafra (1711/1717/1730), Joanina (1717–1728), Aqueduto (1731/1748), Companhia do Douro (1756), Aulas Régias (1759), Vila Real de Santo António (1774), Cortes (última reunião 1697–98).
